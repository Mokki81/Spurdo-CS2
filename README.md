# Spurdo CS2 External xDDD

External overlay for Counter-Strike 2 (Spurdo-style).

## Features

### AIMBOT
- FOV / Smooth / Hitboxes
- Visible only, Autofire, Autozoom
- RCS (pitch / yaw)

### VISUALS
- Box (corner / full) + Skeleton
- HP bar (gradient + number), Armor bar
- Name, Weapon, Weapon icon
- Scoped / Defusing / Flashed
- Off-screen arrows

### NADES
- Flight trajectory
- Smoke / Molly / HE radii

### MISC / OTHER
- Bhop, Autostrafe, Radar
- Watermark, Bomb timer, Sniper crosshair
- Spectator list

## Run

```bash
pip install pymem
# Windows: run as Administrator
python Spurdo.py
```

- CS2: **Borderless / Windowed fullscreen**
- Menu: **Insert** or **Home**
- Offsets: **cs2-dumper 2026-10-23**
